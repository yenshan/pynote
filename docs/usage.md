# 使い方

## ファイルと編集

左上の「フォルダー設定」で既存フォルダーを選択します。直下の `.py` ファイルだけを更新日時順に表示します。サブフォルダーの再帰表示は行いません。「新しいファイル」で Python のひな形を作成し、拡張子を省略すると `.py` を付けます。

Ctrl+S（macOS は ⌘S）で保存します。自動保存は行いません。実行前には保存し、未保存のままファイルやフォルダーを切り替える場合は破棄を確認します。

エディタは Python の構文ハイライトと4スペースのインデントに対応します。ファイル内の単語から入力を補完し、Ctrl+Space でも候補を表示します。Tab / Enter で確定し、Esc で閉じます。

Vim スイッチで Vim 操作を有効にできます。`i` で挿入、Esc でノーマルモード、`:w` で保存します。ヤンクしたテキストは OS のクリップボードにもコピーします。フォント・配色設定からフォント、文字サイズ、行間、合字、ライトテーマを変更できます。

## Python 環境の選択

左サイドバーの「Python 環境」を押すと、Jupyter に登録された Python 環境と、以前指定した実行ファイルの一覧を表示します。名前・Python のバージョン・実行ファイルのパスを確認して選択してください。「再取得」で一覧を更新できます。削除済みなどで起動できない環境は理由を表示し、選択できません。

「参照…」で venv 内の Python 実行ファイルを選ぶか、絶対パスを入力して「適用」を押します。Linux/macOS は `.venv/bin/python`、Windows は `.venv\Scripts\python.exe` などを指定します。activate や、PyNote 用の ipykernel のインストールは不要です。

選択はフォルダーごとに保存し、再起動後も復元します。優先順位は「アプリで選択した環境 → `PYNOTE_PYTHON`（または旧 `KATA_PYTHON`）→ PATH の Python」です。一覧の「既定の Python」を選ぶと、フォルダーの指定を解除します。削除された環境が保存されていた場合は、自動で別環境に変更せず、実行時にエラーを表示します。「Python 環境」から選び直してください。

切り替え時には、そのフォルダーの全ファイルの Python セッションとエラー表示を終了・クリアします。コードと AI の会話は保持します。次の実行で新しい環境を起動するため、変数や対話履歴は引き継ぎません。

Jupyter の一覧は登録済み環境を対象とし、すべての venv を検索するものではありません。Jupyter の起動コマンドから Python 実行ファイルを取り出して利用し、カーネル固有の引数や環境変数は引き継ぎません。独自の起動スクリプトを使う登録は、Python 実行ファイルを直接指定してください。

## パッケージのインストール

左サイドバーの「パッケージを追加」を押し、パッケージ名を1つ入力して「インストール」を押します。入力欄はパッケージ名だけです。例：`numpy`、`pandas`、`scikit-learn`。選択中の Python で `python -m pip install` を実行するため、venv を選択していればその環境にインストールします。バージョン指定やコマンドオプション、URL、ローカルファイルの指定は受け付けません。

ダイアログにインストール先・進捗・成功または失敗の結果を表示します。ダイアログを閉じてもインストールは継続し、再び開くと結果を確認できます。「中止」で処理を終了します。インストール中は Python 環境とフォルダーを切り替えられません。アプリを終了すると実行中のインストールも中止します。

選択した環境に pip がない場合や、システム Python がパッケージ変更を制限している場合はエラーを表示します。別環境へのインストールや権限の昇格は行いません。追加したパッケージを実行中の Python で認識できない場合は、ターミナルの ↻ で Python を再起動してください。

## Python の実行と対話

「Python実行」または Ctrl+Enter（macOS は ⌘Enter）で、保存してファイル全体を実行します。ファイルを開くだけでは Python を起動しません。実行完了後は Python 標準の `>>>` プロンプトで、定義した関数や変数を操作できます。

```python
def double(n):
    return n * 2

print(double(3))
```

このファイルを実行すると `6` を表示します。端末で `double(5)` と入力すれば `10` が返ります。`input()` で入力待ちになったときも、端末から入力してください。複数行の定義は通常の Python と同様に、最後に空行を入力します。Tab 補完、上下キーの履歴、Ctrl+C による中断、`help()`、`exit()` を使えます。

「再実行」は Ctrl+C で処理を中断し、ユーザー定義を初期化して保存したファイルを実行します。Python プロセスは維持するため、インポート済みモジュールのキャッシュは保持します。依存モジュールまで読み直したい場合は ↻ で Python を再起動してください。最大6ファイルのセッションを保持し、超過時には古いセッションを終了します。

実行するファイルのフォルダーを作業ディレクトリとし、`__name__` は `__main__`、`__file__` は実行ファイルのパスです。Python のソースエンコーディング宣言にも対応します。`sys.exit()` を実行するファイルでは終了を例外として表示し、対話プロンプトを維持します。端末から `exit()` を入力するとセッションを終了します。

起動・実行の完了待ちは60秒です。時間超過時もプロセスは継続し、端末で入力や中断ができます。

ターミナル右上の配置ボタンでエディタの下／右を切り替えられます。境界をドラッグして領域の大きさを変更できます。

## エラーと AI

構文エラーや Traceback を検知すると、Codex が日本語の説明を生成し、該当箇所に下線と説明を表示します。外部ファイルや対話入力のエラーなど、現在のソースに対応しないエラーは通知に表示します。元の出力は常に端末で確認できます。

AI 解析はチャット履歴と分離され、AI サイドバーを開きません。説明は編集に追従して残り、保存・再実行で消去します。コード変更前の古い解析結果は保存後に反映しません。「エラーを解析」または Ctrl+J → e で直近のエラーを再解析できます。

AI サイドバーでは、現在の未保存コードを含めて質問を送信できます。モデル・推論レベルを選択でき、回答はストリーミング表示します。AI の利用には Codex CLI のログインが必要です。

## ショートカット

| 操作 | Linux / Windows | macOS |
| --- | --- | --- |
| 新規ファイル | Ctrl+N | ⌘N |
| 保存 | Ctrl+S | ⌘S |
| 実行・再実行 | Ctrl+Enter | ⌘Enter |
| ターミナルへ移動 | Ctrl+Shift+J | ⌘J |
| 領域移動 | Ctrl+J → h / j / k / l | 同左 |
| 直近のエラー解析 | Ctrl+J → e | 同左 |
| 実行を中断 | Ctrl+C（端末内） | 同左 |
| ヘルプ | Ctrl+/ | ⌘/ |
